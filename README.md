
# Warehouse Management System

## Төслийн тухай

Энэ нь агуулахын бараа материалын бүртгэл, орлого, зарлага болон үлдэгдлийг хянах зориулалттай сургалтын төсөл юм.

## Миний зорилго

1. JavaScript болон Python ашиглан өгөгдөл боловсруулах чадвараа сайжруулах.
2. SQL болон MySQL ашиглан өгөгдлийн сантай ажиллаж сурах.
3. User Story болон Acceptance Criteria бичиж сурах.
4. GitHub Issue, Branch, Commit, Pull Request ашиглаж сурах.
5. Агуулахын системийг үе шаттай хөгжүүлэх.

## Хэрэглэгчид

- Агуулахын ажилтан — барааны орлого, зарлага бүртгэнэ.
- Менежер — барааны үлдэгдэл болон тайланг хянана.
- Админ — бараа болон хэрэглэгчийн мэдээллийг удирдана.

## Үндсэн боломжууд

- Бараа бүртгэх
- Барааны орлого бүртгэх
- Барааны зарлага бүртгэх
- Үлдэгдэл шалгах
- Бага үлдэгдэл илрүүлэх
- Барааны хөдөлгөөний түүх харах
- Баримт шалгах
- Бараа хайх

## Ашиглах технологи

| Технологи | Зориулалт |
|---|---|
| JavaScript | Frontend болон өгөгдөл боловсруулах |
| Node.js | JavaScript ажиллуулах орчин |
| Python | Backend програмчлал |
| FastAPI | API үүсгэх |
| SQLAlchemy | Өгөгдлийн сантай холбогдох |
| MySQL | Өгөгдөл хадгалах |
| Git | Хувилбарын удирдлага |
| GitHub | Төслийн хамтын ажиллагаа |

## Төслийн бүтэц

- README.md — төслийн танилцуулга
- .gitignore — шаардлагагүй файлуудыг Git-ээс хасах
- docs/ — лабораторийн баримт бичгүүд

## Лабораторийн ажлууд

| Lab | Агуулга |
|---|---|
| L01 | Төслийн эхлэл |
| L02 | GitHub ба хөгжүүлэлтийн орчин |
| L03 | Асуудал ба процесс |
| L04 | User Story ба Acceptance Criteria |
| L05 | Хамрах хүрээ ба эрсдэл |
| L06 | AI ашиглалт ба алдаа оношлох |
| L07 | Шаардлагын уялдаа |

## Хөгжүүлэлтийн орчин

Хөгжүүлэлтийн орчны мэдээллийг `docs/environment.md` файлаас харна.

## Баримт бичиг

Бүх лабораторийн баримт `docs/` хавтаст байрлана.

## Аюулгүй байдал

Нууц үг, API token, `.env` файл болон database dump-ийг GitHub-д оруулахгүй.

## Төслийн одоогийн үе шат

L01–L07: Шаардлага, төлөвлөлт болон GitHub баримт бичгийн шат.

Дараагийн шатанд өгөгдлийн сан болон Backend хөгжүүлнэ.
