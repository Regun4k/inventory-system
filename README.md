# Inventory System

Inventory management system - learning project.

## Төслийн зорилго

Энэхүү төсөл нь агуулахын бараа бүтээгдэхүүний орлого, зарлага болон үлдэгдлийг бүртгэж, хянах зориулалттай. Систем нь барааны мэдээллийг төвлөрүүлэн хадгалж, агуулахын ажилтанд мэдээллийг ойлгомжтой байдлаар ашиглах боломж олгоно.

## Хэрэглэгчид

- **Нярав** – барааны орлого, зарлага болон үлдэгдлийг бүртгэнэ.
- **Менежер** – агуулахын мэдээлэл болон барааны үлдэгдлийг хянаж ашиглана.
- **Админ** – системийн хэрэглэгч болон үндсэн тохиргоог удирдана.

## Ашиглах технологи

| Технологи | Үүрэг |
|---|---|
| **JavaScript** | Веб хуудасны хэрэглэгчийн талын үйлдэл болон интерактив ажиллагааг хэрэгжүүлнэ. |
| **Node.js** | JavaScript кодыг сервер талд ажиллуулах орчин болгон ашиглана. |
| **Python** | Сервер талын програмчлал болон бизнес логикийг хэрэгжүүлэхэд ашиглана. |
| **FastAPI** | Python дээр API үүсгэж, клиент болон сервер хооронд мэдээлэл дамжуулахад ашиглана. |
| **SQLAlchemy** | Python програм болон өгөгдлийн сан хоорондын харилцааг ORM хэлбэрээр зохицуулна. |
| **MySQL** | Бараа, орлого, зарлага, үлдэгдэл зэрэг өгөгдлийг хадгална. |

## Төслийн бүтэц

Систем нь хэрэглэгчийн интерфейс, сервер талын API болон өгөгдлийн сангийн хэсгүүдээс бүрдэнэ.

Хэрэглэгчийн үйлдэл серверийн API-д хүсэлт илгээж, сервер шаардлагатай мэдээллийг боловсруулан өгөгдлийн сантай харилцана.
