
# L06 — AI ашигласан тэмдэглэл

## 1. Асуудал

GitHub repository дээр L07-ийн traceability файлын байрлал шаардлагатай хавтастай зөрж байгааг анзаарсан.

## 2. AI-д тавьсан асуулт

GitHub дээр файл харагдахгүй эсвэл шаардлагатай хавтас дотор байхгүй үед ямар шалтгаан байж болох вэ?

Код бичихгүйгээр 3 боломжит шалтгаан болон шалгах аргыг тайлбарла.

## 3. AI-ийн санал болгосон таамаглалууд

### Таамаглал 1

Файл буруу хавтас дотор байгаа байж болно.

Шалгах арга:
- Repository-ийн үндсэн хавтсыг нээх.
- Файлын байрлалыг шалгах.

### Таамаглал 2

Файлыг commit хийгээгүй байж болно.

Шалгах арга:
- Commit history шалгах.
- GitHub дээр файл харагдаж байгаа эсэхийг шалгах.

### Таамаглал 3

Өөр branch дээр файл үүсгэсэн байж болно.

Шалгах арга:
- Одоогийн branch-ийг шалгах.
- Main branch дээр файл байгаа эсэхийг шалгах.

## 4. Миний хийсэн шалгалт

- Өөрийн GitHub repository-г нээсэн.
- Main branch-ийг шалгасан.
- `traceability.md` файлыг хайсан.
- Файл repository-ийн үндсэн хавтаст байгааг харсан.

## 5. Шалгалтын үр дүн

Хүлээсэн үр дүн:

`docs/traceability.md` хэлбэрээр файл байрлах ёстой.

Ажигласан үр дүн:

`traceability.md` файл үндсэн хавтаст байрлаж байсан.

Ингэснээр файл огт commit хийгдээгүй гэсэн таамаглал буруу болох нь харагдсан.

Харин файлын байрлалын асуудал байгааг тогтоосон.

## 6. Миний хийх засвар

1. `docs` хавтас руу орох.
2. `traceability.md` файл үүсгэх.
3. Шаардлагын уялдааны мэдээллийг оруулах.
4. GitHub дээр байрлалыг шалгах.

## 7. Миний дүгнэлт

AI-ийн санал болгосон бүх таамаглалыг шууд зөв гэж үзээгүй.

GitHub дээр бодит файлын байрлалыг шалгаж, буруу байсан таамаглалыг няцаасан.

Цаашид AI-ийн зөвлөгөөг өөрийн орчинд шалгаж байж ашиглана.
