# Baseline

## 1. Агуулахын орлого, зарлага, үлдэгдэл

Орлого гэдэг нь агуулахад бараа нэмэгдэх үйлдэл.

Зарлага гэдэг нь агуулахаас бараа хасагдах үйлдэл.

Үлдэгдэл гэдэг нь тухайн барааны одоогийн байгаа тоо.

Ерөнхий дүрэм:

Шинэ үлдэгдэл = өмнөх үлдэгдэл + орлого - зарлага

Зарлагын тоо үлдэгдлээс их байвал зарлагыг зөвшөөрөхгүй бөгөөд өмнөх үлдэгдэл өөрчлөгдөхгүй байх ёстой.

## 2. JavaScript оролдлого

5 барааны массиваас бага үлдэгдэлтэй барааг тодорхойлох оролдлого хийсэн.

Жишээ өгөгдөл:

- A бараа: 20
- B бараа: 5
- C бараа: 12
- D бараа: 2
- E бараа: 18

Хүлээгдэж буй үр дүн:

D бараа хамгийн бага үлдэгдэлтэй.

## 3. Python оролдлого

Ижил өгөгдлийг Python хэлээр туршиж үзсэн.

Ажиглалт:

JavaScript болон Python хэлний синтакс өөр боловч барааны үлдэгдлийг хооронд нь харьцуулах үндсэн логик ижил байна.

## 4. SQL оролдлого

|---|---|

| 2 | Book |

| name | quantity |
