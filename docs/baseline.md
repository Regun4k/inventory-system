
# L01 — Төслийн эхлэл ба суурь үнэлгээ

## 1. Төслийн зорилго

Агуулахын барааны орлого, зарлага болон үлдэгдлийг бүртгэж хянах систем хийх.

Энэ төслөөр JavaScript, Python, SQL болон GitHub ашиглаж сурах зорилготой.

## 2. Агуулахын үндсэн ойлголт

**Орлого:** Агуулахад шинэ бараа нэмэгдэх үйлдэл.

**Зарлага:** Агуулахаас бараа гарах үйлдэл.

**Үлдэгдэл:** Агуулахад одоо байгаа барааны тоо хэмжээ.

Жишээ:

- Эхний үлдэгдэл: 10
- Орлого: 5
- Зарлага: 3
- Эцсийн үлдэгдэл: 12

Тооцоолол:

10 + 5 - 3 = 12

## 3. Туршилтын барааны мэдээлэл

| SKU | Барааны нэр | Үлдэгдэл |
|---|---|---:|
| A01 | Цаас | 10 |
| A02 | Үзэг | 3 |
| A03 | Дэвтэр | 7 |
| A04 | Хавтас | 2 |
| A05 | Баллуур | 6 |

Бага үлдэгдлийн босго: 5

## 4. JavaScript туршилт

```javascript
const items = [
  { sku: "A01", name: "Цаас", balance: 10 },
  { sku: "A02", name: "Үзэг", balance: 3 },
  { sku: "A03", name: "Дэвтэр", balance: 7 },
  { sku: "A04", name: "Хавтас", balance: 2 },
  { sku: "A05", name: "Баллуур", balance: 6 }
];

const lowStock = items.filter(
  item => item.balance < 5
);

console.log(lowStock);
```

Хүлээгдэж буй үр дүн:

- A02 — Үзэг — 3
- A04 — Хавтас — 2

## 5. Python туршилт

```python
items = [
    {"sku": "A01", "name": "Цаас", "balance": 10},
    {"sku": "A02", "name": "Үзэг", "balance": 3},
    {"sku": "A03", "name": "Дэвтэр", "balance": 7},
    {"sku": "A04", "name": "Хавтас", "balance": 2},
    {"sku": "A05", "name": "Баллуур", "balance": 6}
]

low_stock = [
    item for item in items
    if item["balance"] < 5
]

print(low_stock)
```

Хүлээгдэж буй үр дүн:

- A02 — Үзэг — 3
- A04 — Хавтас — 2

## 6. SQL JOIN туршилт

Хоёр хүснэгтийн мэдээллийг холбохын тулд JOIN ашиглана.

Жишээ хүснэгт:

**items**

| id | name |
|---:|---|
| 1 | Цаас |
| 2 | Үзэг |
| 3 | Дэвтэр |
| 4 | Хавтас |
| 5 | Баллуур |

**stock**

| item_id | balance |
|---:|---:|
| 1 | 10 |
| 2 | 3 |
| 3 | 7 |
| 4 | 2 |
| 5 | 6 |

SQL query:

```sql
SELECT
    items.name,
    stock.balance
FROM items
JOIN stock
ON items.id = stock.item_id;
```

Хүлээгдэж буй үр дүн:

| name | balance |
|---|---:|
| Цаас | 10 |
| Үзэг | 3 |
| Дэвтэр | 7 |
| Хавтас | 2 |
| Баллуур | 6 |

Энэ нь JOIN query-ийн гараар таамагласан үр дүн бөгөөд бодит MySQL дээр ажиллуулж шалгах ажил дараагийн шатанд хийгдэнэ.
