# User Stories

## US-01: Бараа бүртгэх
As a нярав
I want to шинэ бараа бүртгэх
So that үлдэгдэл хянах боломжтой

### Acceptance Criteria
- AC-01: Шинэ SKU-тэй бараа 201 буцаана (Хэвийн)
- AC-02: Давхар SKU 409 буцаана (Алдаа)
- AC-03: Хоосон нэр 422 буцаана (Алдаа)

## US-02: Орлого бүртгэх
As a нярав
I want to орлогын баримт үүсгэх
So that үлдэгдэл нэмэгдэх

### Acceptance Criteria
- AC-04: Opening 10 → үлдэгдэл 10 (Хэвийн)
- AC-05: Receipt +5 → үлдэгдэл 15 (Хэвийн)
- AC-06: Draft төлөвт үлдэгдэл өөрчлөгдөхгүй (Хил зааг)

## US-03: Зарлага бүртгэх
As a нярав
I want to зарлагын баримт үүсгэх
So that үлдэгдэл хасагдах

### Acceptance Criteria
- AC-07: 10-аас 10 зарлага → үлдэгдэл 0 (Хил зааг)
- AC-08: 10-аас 11 зарлага → 409, үлдэгдэл 10 хэвээр (Алдаа)
- AC-09: Сөрөг тоо 422 буцаана (Алдаа)

## US-04: Үлдэгдэл харах
As a менежер
I want to үлдэгдлийн тайлан харах
So that шийдвэр гаргах

### Acceptance Criteria
- AC-10: Агуулахаар шүүх боломжтой (Хэвийн)
- AC-11: Бараагаар шүүх боломжтой (Хэвийн)
- AC-12: 0 үлдэгдэл харагдана (Хил зааг)

## US-05: Баримт батлах
As a нярав
I want to draft баримтыг батлах
So that үлдэгдэлд нөлөөлөх

### Acceptance Criteria
- AC-13: Posted баримт засах боломжгүй (Алдаа)
- AC-14: Давхар post 409 буцаана (Алдаа)
- AC-15: Батлалт transaction-д хийгдэнэ (Хэвийн)

## US-06: Буцаалт хийх
As a менежер
I want to posted баримтыг буцаах
So that алдаа засах

### Acceptance Criteria
- AC-16: Бүтэн reversal хийгдэнэ (Хэвийн)
- AC-17: Дахин reversal татгалзана (Алдаа)
- AC-18: Эх баримтын холбоос хадгалагдана (Хэвийн)

## US-07: Хэрэглэгч нэвтрэх
As a хэрэглэгч
I want to системд нэвтрэх
So that эрхээрээ ажиллах

### Acceptance Criteria
- AC-19: Token-гүй 401 буцаана (Алдаа)
- AC-20: Viewer write 403 буцаана (Алдаа)
- AC-21: Clerk зөв урсгал амжилттай (Хэвийн)

## US-08: Аудит харах
As a админ
I want to аудитын мөр харах
So that хэн юу хийснийг мэдэх

### Acceptance Criteria
- AC-22: Actor, цаг, үйлдэл харагдана (Хэвийн)
- AC-23: Password/token хадгалагдахгүй (Алдаа)
- AC-24: Шалтгаан бичигдэнэ (Хэвийн)

## AC-25: Нөөц хүрэлцэхгүй үед
- Оролт: 10 үлдэгдэлтэй, 11 зарлага
- Гаралт: 409 Conflict, үлдэгдэл 10 хэвээр
- Шалгалт: stock_balances өөрчлөлт байхгүй
