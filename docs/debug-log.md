## 5. Таамаглал ба дүгнэлт

1. Файл буруу хавтаст байна гэсэн анхны асуудлыг feature branch дээр `docs/traceability.md` замаар зассан.
2. Файл огт commit хийгдээгүй гэсэн таамаглал тохирохгүй: feature branch дээр файл нээгдэж байна.
3. Branch-ийг шалгах шаардлага бодит байсан: засвар PR-ийн feature branch дээр байрлаж байна.

## 6. Merge Conflict судалгаа

Merge conflict гэдэг нь хоёр branch дээр ижил хэсгийг өөр өөрөөр өөрчилсөн үед үүсэж болох зөрчил юм.

Шийдэхдээ:
1. Зөрчилтэй файлыг нээнэ.
2. Өөрчлөлтүүдийг харьцуулна.
3. Зөв хувилбарыг сонгоно.
4. Conflict тэмдэглэгээг арилгана.
5. Commit хийж дахин шалгана.

Эх сурвалж:

https://docs.github.com/en/pull-requests/reference/merge-conflicts
