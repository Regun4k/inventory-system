
# L06 — Алдаа оношилсон тэмдэглэл

## 1. Шалгах асуудал

L07-ийн `traceability.md` файл шаардлагатай `docs` хавтас дотор биш, repository-ийн үндсэн хавтаст байрласан байсан.

## 2. Хүлээсэн үр дүн

Файл дараах байрлалд байх ёстой.

`docs/traceability.md`

## 3. Ажигласан үр дүн

Одоогийн байрлал:

`traceability.md`

Файл үндсэн хавтаст харагдсан.

## 4. Боломжит шалтгаан

1. Файл буруу хавтаст үүссэн.
2. Өөрчлөлт commit хийгдээгүй.
3. Өөр branch дээр ажилласан.

## 5. Алдаа шалгах алхам

1. GitHub repository нээсэн.
2. Main branch сонгосон.
3. Файлын нэрийг хайсан.
4. Файлын байрлалыг шалгасан.

## 6. Шалгалтын дүгнэлт

Файл GitHub дээр байгаа учраас commit хийгдээгүй гэсэн таамаглал тохирохгүй.

Харин файл буруу хавтаст байрласан нь харагдсан.

Засварын дараа `docs/traceability.md` замыг дахин шалгана.

## 7. Merge Conflict судалгаа

Merge conflict гэдэг нь хоёр branch дээр ижил хэсгийг өөр өөрөөр өөрчилсөн үед үүсэж болох зөрчил юм.

Шийдэхдээ:

1. Зөрчилтэй файлыг нээнэ.
2. Өөрчлөлтүүдийг харьцуулна.
3. Зөв хувилбарыг сонгоно.
4. Conflict тэмдэглэгээг арилгана.
5. Commit хийж дахин шалгана.

Эх сурвалж:

https://docs.github.com/en/pull-requests/reference/merge-conflicts

## 8. Миний дүгнэлт

Алдаа оношлохдоо эхлээд бодит ажиглалтаа шалгах хэрэгтэйг ойлгосон.

Нэг удаад нэг шалтгааныг шалгаж, үр дүнг тэмдэглэх нь зөв арга юм.

Merge conflict гарсан үед өөрчлөлт бүрийг ойлгож байж шийдэх шаардлагатай.
