
# L03 — Асуудал, оролцогч ба процесс

## 1. Төслийн асуудал

Агуулахын барааг гараар бүртгэх үед барааны үлдэгдэл зөрөх, ижил бараа давхар бүртгэгдэх, орлого зарлагын мэдээлэл алдагдах зэрэг асуудал гарч болно.

Тиймээс барааны мэдээлэл болон хөдөлгөөнийг нэг системээр бүртгэж хянах шаардлагатай.

## 2. Оролцогчид

### 2.1 Агуулахын ажилтан

- Бараа хүлээн авна.
- Орлого бүртгэнэ.
- Зарлага бүртгэнэ.
- Барааны үлдэгдэл шалгана.

### 2.2 Менежер

- Барааны үлдэгдэл хянана.
- Орлого, зарлагын мэдээлэл шалгана.
- Бага үлдэгдэлтэй барааг хянана.
- Тайлан мэдээлэл ашиглана.

### 2.3 Админ

- Барааны мэдээлэл удирдана.
- Хэрэглэгчийн мэдээлэл удирдана.
- Системийн үндсэн тохиргоо хариуцна.

## 3. Оролцогчдоос тодруулах асуулт

| Оролцогч | Асуулт |
|---|---|
| Агуулахын ажилтан | Бараа ирэхэд хэрхэн бүртгэдэг вэ? |
| Агуулахын ажилтан | Бараа гаргахдаа үлдэгдлийг хэрхэн шалгадаг вэ? |
| Менежер | Ямар тайлан хамгийн их хэрэгтэй вэ? |
| Менежер | Бага үлдэгдэлтэй барааг хэрхэн мэддэг вэ? |
| Админ | Хэрэглэгч болон барааны мэдээллийг хэрхэн удирддаг вэ? |

Эдгээр асуултыг бодит хэрэглэгчээс асууж, хариултыг дараа нь нэмэлтээр тэмдэглэнэ.

## 4. Илэрч болох асуудлууд

| № | Асуудал | Үр дагавар |
|---|---|---|
| 1 | Ижил SKU давхар бүртгэгдэх | Барааны бүртгэл давхардана |
| 2 | Үлдэгдэл хүрэлцэхгүй үед зарлага хийх | Сөрөг үлдэгдэл үүсэх эрсдэлтэй |
| 3 | Баримтын мэдээлэл зөрөх | Буруу бүртгэл үүснэ |
| 4 | Гараар буруу тоо оруулах | Үлдэгдэл зөрнө |
| 5 | Бага үлдэгдлийг мэдэхгүй байх | Бараа дуусах эрсдэлтэй |
| 6 | Хөдөлгөөний түүх байхгүй | Хяналт хийхэд хүндрэлтэй |
| 7 | Барааны мэдээлэл дутуу байх | Барааг танихад хүндрэлтэй |
| 8 | Орлого, зарлага давхар бүртгэгдэх | Үлдэгдэл буруу болно |

## 5. Одоогийн процесс

Бараа ирэх

→ Баримт шалгах

→ Бараа шалгах

→ Орлого бүртгэх

→ Үлдэгдэл нэмэгдэх

→ Зарлагын хүсэлт

→ Үлдэгдэл шалгах

→ Хүрэлцвэл зарлага бүртгэх

→ Үлдэгдэл хасах

## 6. Оролт ба гаралт

| Үйлдэл | Оролт | Процесс | Гаралт |
|---|---|---|---|
| Орлого | SKU, бараа, тоо | Баримт шалгаж бүртгэх | Нэмэгдсэн үлдэгдэл |
| Зарлага | SKU, тоо | Үлдэгдэл шалгах | Хасагдсан үлдэгдэл |
| Хайлт | SKU | Бараа хайх | Барааны мэдээлэл |
| Үлдэгдэл | Барааны мэдээлэл | Тоо шалгах | Одоогийн үлдэгдэл |

## 7. Гол шаардлага

Агуулахын систем нь барааны орлого, зарлага болон үлдэгдлийг зөв бүртгэх ёстой.

Мөн давхар SKU, буруу тоо хэмжээ болон нөөц хүрэлцэхгүй зарлагыг хянах шаардлагатай.

## 8. Дүгнэлт

Энэ лабораторийн ажлаар агуулахын системийн хэрэглэгчид болон үндсэн процессуудыг тодорхойлсон.

Мөн системд гарч болох асуудлуудыг жагсаасан.

Дараагийн шатанд эдгээр асуудалд үндэслэн User Story бичнэ.
