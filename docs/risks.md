
# L05 — Эрсдэлийн төлөвлөгөө

## 1. Цаг хугацаа хүрэлцэхгүй байх

- Эрсдэл: Төлөвлөсөн ажлууд хугацаандаа дуусахгүй байх.
- Хариуцах хүн: Би.
- Шийдэл: Эхлээд үндсэн функцуудыг хийж, нэмэлт ажлуудыг дараа нь хийх.

## 2. Интернэт тасрах

- Эрсдэл: GitHub ашиглах боломжгүй болох.
- Хариуцах хүн: Би.
- Шийдэл: Хийх ажлаа компьютер дээр хадгалж, интернэт сэргэсний дараа GitHub-д оруулах.

## 3. Git алдаа гарах

- Эрсдэл: Branch, Commit болон Merge хийхэд алдаа гарах.
- Хариуцах хүн: Би.
- Шийдэл: Алдааны мэдээллийг уншиж, нэг өөрчлөлт хийгээд дахин шалгах.

## 4. Технологи ойлгохгүй байх

- Эрсдэл: Python, SQL болон API ашиглахад хүндрэл гарах.
- Хариуцах хүн: Би.
- Шийдэл: Албан ёсны баримт бичиг уншиж, жижиг жишээгээр туршиж сурах.

## 5. Ажлын хэмжээ нэмэгдэх

- Эрсдэл: Төлөвлөөгүй нэмэлт функцууд үндсэн ажлыг удаашруулах.
- Хариуцах хүн: Би.
- Шийдэл: Үндсэн шаардлагуудыг эхэлж дуусгаад нэмэлт боломжуудыг дараа нь хийх.

## 6. Эрсдэлийг хянах

| Эрсдэл | Нөлөө | Хариу арга хэмжээ |
|---|---|---|
| Цаг хүрэхгүй | Өндөр | Ажлаа эрэмбэлэх |
| Интернэт тасрах | Дунд | Локал хадгалалт |
| Git алдаа | Дунд | Алдааг тусад нь шалгах |
| Технологи ойлгохгүй | Өндөр | Жижиг жишээгээр сурах |
| Ажлын хэмжээ нэмэгдэх | Өндөр | Scope хязгаарлах |

## 7. Дүгнэлт

Төслийн явцад гарч болох 5 үндсэн эрсдэлийг тодорхойлсон.

Эрсдэл бүрд хариуцах хүн болон шийдвэрлэх аргыг төлөвлөсөн.
