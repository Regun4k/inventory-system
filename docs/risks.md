
# Risk Management – Warehouse Management System

## Зорилго

Төслийг хэрэгжүүлэх явцад гарч болох эрсдэлийг урьдчилан тодорхойлж, тэдгээрийг бууруулах арга хэмжээ төлөвлөх.

## Эрсдэлийн бүртгэл

### R1 – Цаг хугацаа хүрэлцэхгүй байх
- **Магадлал:** Дунд
- **Нөлөөлөл:** Өндөр
- **Шалтгаан:** Төслийн ажлыг хугацаанд нь дуусгаж амжихгүй байх.
- **Шийдэл:** Ажлаа жижиг хэсэгт хувааж, чухал ажлыг эхэлж хийх.

### R2 – Интернэт тасалдах
- **Магадлал:** Дунд
- **Нөлөөлөл:** Дунд
- **Шалтгаан:** GitHub болон онлайн эх сурвалж ашиглах боломжгүй болох.
- **Шийдэл:** Файлуудаа компьютер дээр хадгалж, интернэттэй үед GitHub руу оруулах.

### R3 – Git болон GitHub алдаа гарах
- **Магадлал:** Дунд
- **Нөлөөлөл:** Өндөр
- **Шалтгаан:** Branch, commit, merge хийх үед алдаа гарах.
- **Шийдэл:** Өөрчлөлт бүрийн дараа commit хийж, branch-аа шалгах.

### R4 – Технологи болон код ойлгоход хүндрэл гарах
- **Магадлал:** Өндөр
- **Нөлөөлөл:** Дунд
- **Шалтгаан:** JavaScript, Python болон SQL-ийн мэдлэг дутмаг байх.
- **Шийдэл:** Алхам алхмаар суралцаж, жишээ код ажиллуулан шалгах.

### R5 – Төслийн ажлын хүрээ хэт томрох
- **Магадлал:** Дунд
- **Нөлөөлөл:** Өндөр
- **Шалтгаан:** Үндсэн шаардлагаас гадуур нэмэлт боломжуудыг хэт их оруулах.
- **Шийдэл:** Эхлээд L01–L07 болон үндсэн шаардлагуудаа дуусгаж, дараа нь нэмэлт боломжуудыг төлөвлөх.

## Эрсдэлийг хянах

- Эрсдэлийг тогтмол шалгах.
- Шинэ эрсдэл гарвал бүртгэлд нэмэх.
- Эрсдэл үүссэн тохиолдолд төлөвлөсөн шийдлийг хэрэгжүүлэх.
- Хэрэгжүүлсэн арга хэмжээний үр дүнг тэмдэглэх.

## Тайлбар

Эдгээр нь төслийн явцад гарч болох эрсдэлийн төлөвлөгөө юм. Бодит эрсдэл үүссэн эсэхийг тусад нь тэмдэглэнэ.
