## 5. Шинэ нөхцөлийн хамгаалалтын даалгавар

**Нөхцөл:** Нэг SKU бараа хоёр өөр агуулахад хадгалагддаг бол үлдэгдлийг хэрхэн шалгах вэ?

**Өөрчлөх Story:** US-04 — Барааны үлдэгдэл шалгах.

**Шинэ User Story (санал):** Агуулахын менежерийн хувьд би SKU болон агуулах тус бүрээр үлдэгдлийг харахыг хүсэж байна. Ингэснээр аль агуулахад хэдэн ширхэг бараа байгааг ялгаж чадна.

**Шинэ Acceptance Criteria (санал):**
1. Ижил SKU хоёр агуулахад байвал агуулах тус бүрийн үлдэгдлийг тусад нь харуулна.
2. Нийт үлдэгдэл нь агуулах тус бүрийн үлдэгдлийн нийлбэртэй тэнцүү байна.
3. Тухайн агуулахад үлдэгдэл 0 бол 0 гэж харуулна; тухайн SKU огт байхгүй бол олдсонгүй гэж мэдээлнэ.

**Хамгаалалтын тэмдэглэл:** Энэ бол шинэ нөхцөлд гаргасан саналын жишээ. Оюутан өөрийн үгээр тайлбарлаж, багшийн нэмэлт нөхцөлд өөрөө өөрчлөх ёстой.

## 8. Дүгнэлт

Энэ шатанд шаардлагын баримт, төлөвлөгөө, AI/debug тэмдэглэл болон GitHub нотолгоог нэгтгэв. Бодит хамгаалалт, peer review, багшийн үнэлгээ хийгдээгүй тул G1 PASS гэж урьдчилан тэмдэглээгүй.

Хамгаалалтын дараа:
- Ямар чадвар нэмэгдсэн;
- Ямар нотолгоо үүнийг харуулсан;
- Ямар алдаа давтагдсан;
- AI-ийн ямар зөвлөгөөг зөвшөөрсөн/няцаасан;
- Дараагийн шатанд юуг нөхөхийг бөглөнө.
