## 4. Багшийн review-ээс хийсэн тодруулга

- Орлогын DRAFT баримт үлдэгдэлд нөлөөлөхгүй; зөвхөн POSTED батлалт үлдэгдлийг нэмнэ.
- Нэг баримтыг дахин батлахгүй; давхар хөдөлгөөн үүсгэхгүй.
- POSTED баримтыг шууд засахгүй, reversal баримтаар залруулна.
- Энэ хувилбарт тоо хэмжээ бүхэл тоо байх тул 2.5 зэрэг утгыг татгалзана.
- Бүртгэлтэй SKU тухайн агуулахад хөдөлгөөнгүй байвал үлдэгдэл 0; харин лавлахад огт байхгүй SKU бол “олдсонгүй”.
- Нийт үлдэгдэл нь агуулах тус бүрийн нийлбэр байна.

## 5. Хоёр агуулахын шинэ нөхцөл

**Нөхцөл:** P01 бараа барааны лавлахад бүртгэлтэй. A агуулахад 10 ширхэг, B агуулахад хөдөлгөөн байхгүй.

**Хүлээгдэж буй үр дүн:** A = 10, B = 0, нийт = 10.

**Өөр нөхцөл:** X99 SKU барааны лавлахад огт байхгүй.

**Хүлээгдэж буй үр дүн:** “Олдсонгүй” гэж мэдээлнэ. Энэ нь бүртгэлтэй SKU тухайн агуулахад 0 үлдэгдэлтэй байхаас өөр нөхцөл юм.

Эдгээр дүрмийг [requirements.md](../requirements.md)-ийн US-04, AC-10–AC-12 болон бизнес дүрэмд тусгасан.

Өөр суралцагчаар PR #6-г шалгуулж, хоёр тодорхойгүй нөхцөл болон түүнд өгсөн шийдвэрийг [peer-review.md](peer-review.md)-д бодитоор тэмдэглэнэ.
