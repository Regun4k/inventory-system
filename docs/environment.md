
# L02 — Хөгжүүлэлтийн орчин

## 1. Ашиглаж буй компьютер

- Үйлдлийн систем: Windows 11
- Компьютер: Lenovo

## 2. Суулгасан технологи

| Технологи | Хувилбар |
|---|---|
| Node.js | v24.13.0 |
| Python | 3.14.3 |
| MySQL | 9.2 |
| Git | 2.53.0 |

Эдгээр хувилбарыг өөрийн компьютер дээр командаар шалгана.

## 3. Хувилбар шалгах команд

```bash
node --version
python --version
mysql --version
git --version
```

## 4. Ашиглах технологи

- JavaScript
- Python
- FastAPI
- MySQL
- SQLAlchemy
- Git
- GitHub

## 5. Ажиллуулах дараалал

Одоогоор төсөл нь баримт бичиг болон шаардлага тодорхойлох шатандаа байгаа.

Backend болон Frontend бүрэн хийгдсэний дараа:

1. MySQL database ажиллуулах.
2. Python virtual environment идэвхжүүлэх.
3. Backend сервер ажиллуулах.
4. Frontend ажиллуулах.
5. API болон database холболтыг шалгах.

## 6. GitHub ашиглах дараалал

1. Issue үүсгэх.
2. Feature branch үүсгэх.
3. Файл нэмэх эсвэл засах.
4. Commit хийх.
5. Pull Request нээх.
6. Review авах.
7. Merge хийх.

## 7. Аюулгүй байдал

- Нууц үг GitHub-д оруулахгүй.
- `.env` файлыг commit хийхгүй.
- API token нийтлэхгүй.
- Database password-ийг код дотор шууд бичихгүй.

## 8. Дүгнэлт

Хөгжүүлэлтийн орчинд шаардлагатай үндсэн програмуудыг суулгасан.

Цаашид эдгээр технологийг ашиглан агуулахын системийг хөгжүүлнэ.
