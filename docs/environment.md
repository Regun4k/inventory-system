
# Development Environment

## Ашиглах технологиуд

Энэ төсөлд дараах технологиудыг ашиглана:

- Node.js
- Python
- MySQL
- Git

## Хувилбарын мэдээлэл

Төслийг хөгжүүлэхэд ашиглаж буй технологиудын хувилбар:

- Node.js: v22.14.0
- Python: 3.13.2
- MySQL: 8.0.41
- Git: 2.49.0

## Хувилбар шалгах

Суулгасан хувилбарыг шалгахын тулд Terminal дээр дараах командуудыг ажиллуулна.

```bash
node --version
python --version
mysql --version
git --version
```

## Тохиргоо

Төслийг ажиллуулахын өмнө шаардлагатай технологиудыг компьютерт суулгасан байна.

Нууц мэдээлэл болон орчны хувьсагчдыг `.env` файлд хадгална. `.env` файлд агуулагдах нууц мэдээллийг GitHub repository-д оруулахгүй.

## Git ашиглах

Төслийн өөрчлөлтийг Git ашиглан бүртгэж, GitHub repository руу push хийнэ.

Өөрчлөлтөө commit хийхийн өмнө файлуудаа шалгаж, шаардлагагүй болон нууц мэдээлэл агуулсан файлуудыг оруулаагүй эсэхийг нягтална.
