## 3. Шинэ нөхцөлийн ялгаа — хоёр агуулах

- **Бараа бүртгэлтэй боловч агуулахад хөдөлгөөнгүй:** P01 барааны лавлахад байна. A-д 10 ширхэг, B-д хөдөлгөөн байхгүй бол A: 10, B: 0, нийт: 10.
- **Барааны лавлахад огт байхгүй:** X99 SKU-г хайвал “олдсонгүй” гэж мэдээлнэ.

Ингэснээр “агуулахад 0 үлдэгдэлтэй” болон “системд бараа бүртгэлгүй” хоёр өөр нөхцөл болно.

## 4. Баримтын төлөвийн гол шалгалт

1. DRAFT хадгалах нь үлдэгдэлд нөлөөлөхгүй.
2. POSTED болгох үед л үлдэгдэлд нэг удаа нөлөөлнө.
3. Нэг баримтыг дахин POSTED болгохыг татгалзаж, давхар хөдөлгөөн үүсгэхгүй.
4. POSTED баримтыг шууд засахгүй; reversal баримтаар залруулна.
