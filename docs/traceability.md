# L07 — Шаардлагын уялдаа (Traceability)

Энэ хүснэгт нь `docs/requirements.md` дахь 8 User Story-г шалгах боломжтой acceptance criteria болон төслийн баримттай холбов.

| Story ID | Шаардлага | Хүлээн авах шалгалт | Нотолгоо |
|---|---|---|---|
| US-01 | Бараа бүртгэх | AC: зөв SKU хадгалах; давхардсан SKU татгалзах; шаардлагатай талбар дутуу үед татгалзах | requirements.md §US-01 |
| US-02 | Орлого бүртгэх | AC: эерэг тоо үлдэгдэл нэмэх; 0 ба сөрөг тоог татгалзах | requirements.md §US-02 |
| US-03 | Зарлага бүртгэх | AC: үлдэгдлээс бага үед хасах; тэнцүү үед 0 болгох; их үед татгалзах | requirements.md §US-03 |
| US-04 | Үлдэгдэл шалгах | AC: одоогийн үлдэгдэл харуулах; 0 үлдэгдлийг харуулах; үл мэдэгдэх SKU-д олдсонгүй харуулах | requirements.md §US-04 |
| US-05 | Бага үлдэгдэл | AC: 5-аас багаг илрүүлэх; яг 5-ыг оруулахгүй; SKU/нэр/үлдэгдэл харуулах | requirements.md §US-05 |
| US-06 | Хөдөлгөөний түүх | AC: орлого хадгалах; зарлага хадгалах; хоосон түүхийг зөв харуулах | requirements.md §US-06 |
| US-07 | Баримт шалгах | AC: дугаар хоосон үед татгалзах; огноо/мэдээлэл дутуу үед татгалзах; бүрэн үед үргэлжлүүлэх | requirements.md §US-07 |
| US-08 | Бараа хайх | AC: SKU-аар хайх; нэрээр хайх; олдоогүй үед мэдээлэх | requirements.md §US-08 |

## Ерөнхий бизнес дүрмийн холбоос

- SKU давхцахгүй — US-01 AC-02.
- Тоо хэмжээ сөрөг биш, орлого/зарлага 0-ээс их — US-02, US-03.
- Зарлага үлдэгдлээс ихгүй — US-03 AC-03.
- Бага үлдэгдлийн босго 5 — US-05.
