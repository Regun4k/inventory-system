
# L05 — Хамрах хүрээ ба ажлын төлөвлөгөө

## 1. Төслийн хамрах хүрээ

Энэ төслийн зорилго нь агуулахын барааны бүртгэл, орлого, зарлага болон үлдэгдлийг хянах систем хөгжүүлэх юм.

## 2. Үндсэн ажлууд

### M1 — Барааны бүртгэл

- Барааны SKU бүртгэх.
- Барааны нэр бүртгэх.
- Давхардсан SKU шалгах.
- Шаардлагатай мэдээлэл шалгах.

Дуусах шалгуур: Бараа давхар бүртгэгдэхгүй.

### M2 — Орлогын бүртгэл

- Бараа хүлээн авах.
- Орлогын мэдээлэл бүртгэх.
- Тоо хэмжээ шалгах.
- Үлдэгдэл нэмэгдүүлэх.

Дуусах шалгуур: Зөв орлого үлдэгдлийг нэмэгдүүлнэ.

### M3 — Зарлагын бүртгэл

- Зарлагын хүсэлт авах.
- Үлдэгдэл шалгах.
- Зарлагын мэдээлэл бүртгэх.

Дуусах шалгуур: Үлдэгдэл хүрэлцэхгүй үед зарлага бүртгэгдэхгүй.

### M4 — Үлдэгдэл шалгах

- Бараа тус бүрийн үлдэгдэл харах.
- SKU ашиглан бараа шалгах.
- 0 үлдэгдлийг харуулах.

Дуусах шалгуур: Үлдэгдэл зөв харагдана.

### M5 — Бага үлдэгдэл шалгах

- Бага үлдэгдлийн босго тодорхойлох.
- Үлдэгдэл 5-аас бага барааг шүүх.
- Бага үлдэгдэлтэй барааны жагсаалт гаргах.

Дуусах шалгуур: Бага үлдэгдэлтэй бараа зөв илэрнэ.

### M6 — Баримт шалгах

- Орлогын баримт шалгах.
- Зарлагын баримт шалгах.
- Дутуу мэдээллийг илрүүлэх.

Дуусах шалгуур: Мэдээлэл дутуу баримт хадгалагдахгүй.

### M7 — Бараа хайх

- SKU ашиглан бараа хайх.
- Барааны нэрээр хайх.
- Олдоогүй барааны мэдээлэл харуулах.

Дуусах шалгуур: Хайлтын үр дүн зөв гарна.

### M8 — Тест ба шалгалт

- Хэвийн нөхцөл шалгах.
- 0 тоо хэмжээ шалгах.
- Сөрөг тоо хэмжээ шалгах.
- Давхар SKU шалгах.
- Нөөц хүрэлцэхгүй нөхцөл шалгах.

Дуусах шалгуур: Туршилтын үр дүнг тэмдэглэсэн байна.

## 3. Ажлуудыг жижиг хэсэгт хуваах

| Хэсэг | Хийх ажил |
|---|---|
| Database | Хүснэгт, холбоос үүсгэх |
| API | Барааны мэдээлэл авах, хадгалах |
| UI | Бүртгэл болон хайлтын дэлгэц хийх |
| Test | Зөв болон буруу нөхцөлийг шалгах |

## 4. Нэмэлт ажлууд

- Тайлан гаргах.
- Хэрэглэгчийн эрх нэмэх.
- Олон агуулах дэмжих.
- Интерфейс сайжруулах.
- Барааны зураг оруулах.

Эдгээр ажлыг үндсэн функцууд дууссаны дараа хийнэ.

## 5. Дүгнэлт

Төслийн ажлуудыг 8 хэсэгт хуваасан.

Эхлээд үндсэн бүртгэл болон үлдэгдлийн ажиллагааг хийхээр төлөвлөсөн.

Нэмэлт боломжуудыг дараагийн шатанд хөгжүүлнэ.
